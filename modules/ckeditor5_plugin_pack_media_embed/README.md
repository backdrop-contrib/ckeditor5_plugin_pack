# CKEditor 5 Bookmark

Allows editors to add anchor tags.

This module enables the CKEditor 5 [Bookmark plugin](https://ckeditor.com/docs/ckeditor5/latest/features/bookmarks.html)
included with Backdrop core, but the bookmark plugin is not available by default.

## Installation

- Install this module using the [official Backdrop CMS instructions](https://docs.backdropcms.org/documentation/extend-with-modules).
- Visit admin/config/content/formats to add the new Bookmark buttons to
  your editor's toolbar.
